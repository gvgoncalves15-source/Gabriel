# Logística360 — Painel Operacional

App completo com banco de dados real (Supabase): login, clientes, escalas, equipe, documentos restritos (LGPD) e ocorrências — dados compartilhados entre todos os usuários.

## Como publicar no GitHub Pages

1. No seu repositório no site do GitHub, clique em **Add file → Upload files**.
2. Arraste os arquivos `index.html`, `README.md` e a pasta `assets` (mantendo a estrutura de pastas) para a área de upload.
3. Clique em **Commit changes**.
4. Se o GitHub Pages do repositório já estiver configurado (era o caso, segundo nossa configuração anterior), o site vai publicar sozinho em alguns minutos no endereço `https://gvgoncalves15-source.github.io/Gabriel/`.

## Primeiro acesso

1. Abra o site publicado e clique em **Criar conta**.
2. Toda conta nova entra como **Operador** (não vê documentos restritos por LGPD).
3. Para promover alguém a **Administrador** ou **Supervisor** (libera os documentos restritos), é preciso alterar isso direto no banco — me avise o e-mail da conta que devo promover.
